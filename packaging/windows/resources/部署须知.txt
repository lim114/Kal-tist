思衡托桌宠 2.16.0 · 安装版

支持范围
Windows 10 22H2（Build 19045）或 Windows 11，Intel/AMD x64。
ARM64、32 位 Windows、macOS、Linux 不适用本安装包。
内置 Electron 44.4.5，无需另装 Node.js 或 Python。需要系统 Windows PowerShell 5.1 和 .NET Framework 4.8，安装时会检测。建议至少 1 GB 安装空间、4 GB 内存；显卡需要可用的 WebGL，若受驱动或远程桌面影响可使用兼容模式。

安装与原版共存
双击 Setup.exe，按提示安装到独立目录。默认位置是当前用户 LocalAppData\Programs\EsperantaCompanion，无需管理员权限。不会更新或删除原工作区中的桌宠。
安装版设置、缓存与检测报告保存在 %APPDATA%\EsperantaCompanion。安装包不包含本机登录信息、API 密钥、聊天记录、媒体缓存或窗口位置。首次使用采用默认大小和新电脑上的文档工作目录。
安装在当前电脑时，原版和安装版可以各自保留，但不建议同时启动两份桌宠或同时启用两份跟随启动。

部署检测
安装前检查系统版本、架构、.NET 与 PowerShell；安装后校验程序文件、用户目录写入、磁盘空间、Codex/指令组件、网易云客户端和 Windows 媒体接口。结果写入 environment-report.html / .json，开始菜单与任务面板“环境检测”按钮可以重新运行。
检查在本机进行，不上传账号或对话资料。缺少可选客户端会显示“需配置”，不会阻止安装独立桌宠。关键文件缺失或运行环境不支持会阻止安装完成。

ChatGPT 聊天与工作模式
三模式界面与桥接代码已包含，但不会打包当前电脑的会话绑定、待确认消息或桥接任务标识。新电脑需要使用本机真实任务上下文重新配置桥接并选择会话；未配置时会明确提示“尚未配置本机对话桥接上下文”，Codex 模式可独立使用。本安装包不保证不同客户端版本的内部桥接接口兼容。

Codex
在新电脑安装 Codex，打开并自行登录；先运行一次任务，再进行检测。不会迁移本机账户或自动发送测试指令。任务同步从当前用户的本地 Codex 目录读取，若使用 CODEX_HOME 会遵循该配置。指令组件需先由 Codex 初始化。
在任务面板选择有效的工作目录。不要沿用其他电脑上的磁盘路径。安装向导可选择“随 Codex 启动”，也能在面板中开关；使用独立的当前用户启动项 EsperantaCompanionInstalled，不改动原版启动项。

网易云
请自行安装并登录网易云音乐，播放一首歌后检测。基础歌名、封面与播放控制依赖 Windows 媒体会话。完整进度和循环控制在网易云 3.1.40 上实测；其他客户端版本可能因内部接口变化需要适配。
要启用进度/循环控制，正常退出网易云后使用桌宠里的“打开网易云”启动。程序只连接本机 127.0.0.1:19263，端口冲突或非网易云目标不会被控制。安装与检测不会自动中断音乐、切歌或修改代理。

图形兼容模式
若角色黑屏、无法显示或 WebGL 初始化失败，先退出此安装版桌宠，再从开始菜单运行“兼容模式（软件渲染）”。此模式使用 CPU 渲染本地角色，性能取决于硬件。也可更新显卡驱动后恢复普通入口。不要通过关闭系统安全软件来处理图形问题。

基本操作
拖动角色移动；Ctrl + 滚轮或面板滑条连续调节大小；双击触发原生触摸互动；右键/托盘打开任务面板或气泡。任务面板无系统标题栏，顶部可拖动，内置关闭按钮收起面板。气泡文字标签不可选中，回复可复制。
待机按既定 Relax/Sit 随机逻辑，五分钟后 Sleep；思考为低臂摸下巴及加载指示；等待保持单手叉腰；保留全部当前骨骼、遮挡与眼部追踪设置。

升级与卸载
升级前退出安装版桌宠，运行新版安装包；不要强行覆盖正在运行的文件。卸载从系统“已安装的应用”或开始菜单执行，仅移除本安装版及其启动入口。用户配置目录默认保留，原工作区桌宠和 Codex/网易云不会卸载。
